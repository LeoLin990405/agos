# AgOS 前端设计 Brief(给 agy,2026-08-20)

你是本仓(agos-frontend,dsh 的自有 SPA 前端)的**前端设计与实现者**。第一个交付不是接线代码,是**可点的静态 HTML 原型**——Leo 拍板视觉后才进真实现。

## 背景一分钟

- 本仓将完全替代 dsh 上游前端(P0 契约客户端已完成,见 `README.md`;总体方案 `docs/design/master-plan.md`)。
- 之前在插件层做过一版「遥测甲板+共息」设计(设计稿全文 `docs/design/raw-directions.md`,四路方向:遥测甲板/校样/活体机房/共息动效编排)。**Leo 的反馈:不好看。** 病根不是方向错,是执行怯:空旷(数据少的状态没被设计)、无排印锚点、色彩不敢用、被插件层约束压扁(只能系统字体、套在宿主 modal 里)。
- 本仓没有那些约束:**你可以自托管字体、自由全页布局、大胆用色**。设计稿当参考素材用,不当枷锁——取其骨(等宽数字纪律/灯语四态/运行态才动/共息同频心跳),换其皮,做出胆量。

## 交付物(第一阶段,只做这个)

`prototype/` 目录,纯静态可点 HTML(零构建、双击能开;可用一个共享 CSS):

1. `01-chat.html` —— 对话页:侧栏会话列表 + 消息流(用户/助手气泡、一个流式中的回复、一张工具卡、一张 swarm 批量卡含 8 行子代理四态、一个审批面板)+ 输入框。**用真实感假数据填满**,别再出现空旷。
2. `02-console.html` —— 控制台概览:KPI + 注意力收件箱 + 导航。**必须同时设计「数据少」和「数据满」两种密度**(同一页做两个 section 展示,或做切换)。
3. `03-lineage.html` —— 谱系页:团队/批次分组的子代理 Job 卡、父子血缘线、运行中的行(演示共息心跳——所有运行点同相位呼吸)。

## 硬要求(不可违背)

- **深浅双主题**都要能看(prefers-color-scheme;可默认深色优先)。
- 动效纪律:transform/opacity only;`infinite` 动画只出现在「运行中」元素;失败=静止的红;prefers-reduced-motion 降级。
- 状态四态词表:等待中/处理中/已完成/未成功(+已中止)。
- 中文为主的 UI 文案;数字全部等宽(tabular-nums)。
- 字体如自托管:选可变字重的开源字体(思源黑体/Inter/JetBrains Mono 类),文件放 `prototype/fonts/`,原型阶段 CDN 链接也行(真实现再落本地)。

## 放开的(明确允许,鼓励用)

- 大字号排印时刻(hero 数字/大标题)、有胆量的 accent 用法、真实的背景层次(不止 1px 边框)、图标(SVG 内联)、密度更高的表格/列表。
- 不必兼容旧插件层的任何类名/token——这是新世界,`u-*` 那套只是参考。

## 判分标准(Leo 视角)

打开原型第一眼:「这是个有人设计过的产品」而不是「工程师排的 wireframe」。空态也好看;满态不乱;深浅都成立。

## 之后(拍板后才做,现在不做)

原型定稿 → 抽 design tokens + 组件规范 → 接 P1 数据层(fold/stores,Claude 在做)→ P2 真实现。你的代码 review 由 Claude/Codex 做(既定分工,agy 不做 review)。
